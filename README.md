# 20-20-20 README

`20-20-20` is a cross-platform eye-care timer for iOS, macOS, and watchOS. It helps users follow the 20-20-20 rule: work for 20 minutes, look far away for 20 seconds, then continue through a longer rest cycle.

This repository is also used as a learning project, so the Swift files include many comments explaining why each part exists.

## Features

- Four-step eye-care countdown cycle.
- Circular countdown progress UI.
- Start, pause, reset, and confirm-next-step controls.
- Debug and Release run modes.
- English and Traditional Chinese UI language support.
- iOS Lock Screen / Dynamic Island Live Activity with system-rendered countdown time.
- Live Activity reduced-luminance display support: long countdowns can show `m:--`, while the final minute shows full seconds.
- iOS AlarmKit reminders.
- macOS local notification and in-app alarm sound.
- watchOS countdown app with system haptic / smart alarm behavior.
- iPhone to Apple Watch sync for run mode and preferred language.

For iPhone and Apple Watch testing, use a paired iPhone and Apple Watch destination when available. USB is usually more reliable than wireless for first-time installation.

## Configuration

The App has its own run mode setting. This is different from Xcode's Debug / Release build configuration.

| Mode | Purpose |
| --- | --- |
| `Debug` | Short countdowns for testing notifications, alarms, Live Activity, and Watch behavior. |
| `Release` | Normal 20-20-20 durations for real daily use. |

On iOS, settings are available at:

```text
iPhone Settings > 20-20-20
```

Available settings:

- `Run Mode`: `Debug` / `Release`
- `Preferred Language`: `English` / `繁體中文`

On macOS, settings are available from the App Settings window.

The App UI language is stored with:

```text
app_language_code
```

If no language has been selected yet, the App follows the system language:

- Chinese system language: Traditional Chinese.
- English or non-Chinese system language: English.

## Git Workflow

The project currently uses:

- Local branch: `main`
- GitHub remote branch: `master`

Because the branch names are different, pushing from Terminal should use:

```bash
git push origin HEAD:master
```

Recommended safe flow:

```bash
git status
git add <changed-file-path>
git commit -m "Short commit message"
git push origin HEAD:master
```

For example:

```bash
git add 20-20-20/AppText.swift 20-20-20/SettingsView.swift
git commit -m "Fix language preference sync"
git push origin HEAD:master
```

Use `git add -A` only when you have checked `git status` and really want to include all modified, added, deleted, and moved files.

## Notes

- iOS Settings may show system-managed items such as Mobile Data. Those are added by iOS and are not controlled by `Settings.bundle`.
- The iOS Settings page title is generated by the system from the App name.
- Live Activity behavior should be verified on a real iPhone because Simulator Lock Screen / SpringBoard behavior can differ from real devices.
- Live Activity reduced-luminance / Always-On display behavior should be verified on a real iPhone Lock Screen.
